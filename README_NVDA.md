# SumatraPDF-NVDA (Доступная версия для незрячих пользователей)

Специальная модификация **SumatraPDF** для программ экранного доступа (**NVDA**, **JAWS**).

## Основные отличия от стандартной версии

1. **Текстовый режим чтения вместо графического холста**:
   - Недоступный для скринридеров графический холст (`SUMATRA_PDF_CANVAS`) отключён.
   - Вместо него встроено стандартное многострочное текстовое поле Windows (`Edit`) без ограничения объёма текста.
   - При открытии книги (PDF, DjVu, EPUB, FB2, MOBI, CHM, TXT и др.) фокус сразу встаёт в текст книги — чтение работает стандартными командами NVDA и стрелками клавиатуры, как в обычном текстовом редакторе.

2. **Чёткая текстовая разметка и умная склейка абзацев**:
   - Автоматическая вставка заголовков глав из оглавления: `=== Глава: Название ===`.
   - Разделители страниц: `--- Страница X из Y ---`.
   - Режим **Умных абзацев** (по умолчанию): склеивает разорванные версткой PDF/DjVu строки и переносы слов внутри абзаца для плавного чтения синтезатором речи.

3. **Доступный стартовый экран и удобная навигация**:
   - На стартовом экране выводится памятка по клавишам и пронумерованный список недавних книг (открытие по `Enter` на строке или клавишами `1`–`9`).
   - Всегда включён стандартный заголовок окна Windows и классическое системное меню по клавише `Alt`.
   - Оглавление по `F12` сразу переводит фокус в дерево глав (`Enter` — переход к главе и возврат фокуса в текст, `Esc` — возврат в текст).
   - Поиск по `Ctrl+F` / `F3` автоматически выделяет найденное слово курсором в текстовом поле.

4. **Полностью офлайн**:
   - Полностью вырезаны фоновые сетевые запросы, проверка обновлений и отправка отчётов.

## Горячие клавиши

- `Ctrl+O` — Открыть файл
- `Стрелки Вверх / Вниз`, `Ctrl+Вверх / Вниз` — Чтение по строкам и абзацам
- `PageDown / PageUp` — Листание текста (или страниц в постраничном режиме)
- `Ctrl+PageDown / Ctrl+PageUp` — Переход ровно к началу следующей / предыдущей страницы
- `Ctrl+G` — Перейти к странице по номеру
- `F12` — Оглавление книги (`Enter` — перейти к главе, `Esc` — вернуться в текст)
- `Ctrl+F` — Поиск по книге (`F3` — далее, `Shift+F3` — назад, `Esc` — вернуться в текст)
- `F8` — Переключить режим строк (умные абзацы / оригинальные строки страницы)
- `F9` — Переключить режим загрузки (вся книга / только текущая страница)
- `Alt` — Главное меню SumatraPDF
